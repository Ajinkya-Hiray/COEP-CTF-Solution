COEP CTF — Challenge Write-ups
 
Purpose: Documentation of my CTF challenge-solving process and key learnings.
 
Challenge 1 — View Source
 
Flag: "COEP{view_source_is_your_friend}"
 
Objective: Find information hidden in a webpage.
 
Solution Approach: Inspect the webpage source and look for clues or hidden text.
 
Learning Outcome: Learned how webpage source inspection can reveal information not immediately visible on the page.
 
Challenge 2 — Base64
 
Flag: "COEP{base64_is_not_encryption}"
 
Objective: Identify encoded text and understand its representation.
 
Solution Approach: Identify the Base64-encoded content and decode it to inspect the result.
 
Learning Outcome: Understood that Base64 is an encoding scheme, not encryption.
 
Challenge 3 — Metadata
 
Flag: "COEP{metadata_never_lies}"
 
Objective: Investigate file metadata for clues.
 
Solution Approach: Inspect the challenge file's metadata and examine any relevant information.
 
Learning Outcome: Learned that file metadata can contain useful forensic clues.
 
Challenge 4 — Robots.txt
 
Flag: "COEP{robots_know_secrets}"
 
Objective: Investigate website paths and clues.
 
Solution Approach: Check the website's "robots.txt" file for potentially relevant paths or information.
 
Learning Outcome: Learned the purpose of "robots.txt" and how it can provide clues during web challenges.

Challenge 6 — Mystery JPG
 
Flag: "COEP{not_every_jpg_is_a_jpg}"
 
Objective: Investigate a JPG file and locate the hidden flag.
 
Solution Approach: Inspect the downloaded file and examine its contents to determine whether it contains information beyond an ordinary image.
 
Learning Outcome: Learned the importance of verifying file contents instead of relying only on a file extension.
